# Frontend — متجر اللابتوبات

React + Vite (SPA).

## التقنيات

- **React + Vite** — بدون SSR، تطبيق صفحة واحدة
- **React Router** — التوجيه، بما فيه مسار أدمن محمي (`ProtectedAdminRoute`)
- **react-i18next** — عربي/إنكليزي مع تبديل فوري لاتجاه الصفحة (RTL/LTR)
- **Framer Motion** — الانتقالات والأنيميشن (ظهور عند التمرير، تأثير Tilt ثلاثي الأبعاد على بطاقات المنتجات)
- **Socket.io-client** — استقبال إشعارات فورية (موافقة/رفض الدفع، تغيّر حالة الطلب) في صفحة تتبع الطلب
- **axios** — طبقة API في `src/api/`

## التشغيل

```bash
npm install
npm run dev      # يفتح على http://localhost:5173 (أو منفذ آخر تلقائياً لو كان مشغولاً)
npm run build    # بناء للإنتاج في dist/
```

اضبط `VITE_API_URL` (ملف `.env` أو متغيرات البيئة) إن كان الباك اند على رابط غير `http://localhost:5050`.

## البنية

```
src/
  api/                    عميل axios + دوال كل مورد (public.js للعميل، admin.js للوحة التحكم)
  context/                Theme, Lang (عبر i18next), Cart, GuestId, Socket, Compare, AdminAuth, Settings
  components/             Navbar, بطاقة منتج, شريط سفلي عائم للفئات, شريط المقارنة, فلاتر...
  components/admin/       مكونات خاصة بلوحة التحكم (نموذج منتج ديناميكي, TagListEditor...)
  pages/                  صفحات الموقع العامة (رئيسية, منتجات, سلة, دفع, تتبع طلب...)
  pages/admin/            صفحات لوحة التحكم
  i18n/                   ar.json, en.json
  styles/variables.css    كل ألوان الموقع كمتغيرات CSS — نقطة التخصيص البصري الوحيدة
  utils/                  أيقونات المواصفات, صور بديلة (placeholder) لكل فئة
```

## تخصيص الألوان

كل لون في الموقع (خلفيات، أزرار، شارات، حدود...) معرّف كمتغيّر CSS في [`src/styles/variables.css`](src/styles/variables.css)، بنسختين (فاتح/داكن). لتغيير الهوية البصرية بالكامل، عدّل هذا الملف فقط — لا حاجة للبحث داخل المكوّنات.

## الحالة بدون تسجيل دخول

لا يوجد تسجيل دخول للمستخدمين إطلاقاً. هوية الزائر (للسلة والمقارنة وتتبع الطلب) تُبنى من `guestId` عشوائي يُخزَّن في `localStorage` عبر `GuestIdContext`. الأدمن فقط يسجّل دخول (JWT) عبر رابط 🔒 في شريط التنقل.

## المقارنة بين المنتجات

`CompareContext` يقيّد المقارنة بمنتجات من **نفس الفئة فقط** — بمجرد اختيار أول منتج، تُقفل الفئة وتصبح خانات "قارن" لأي منتج من فئة أخرى معطّلة تلقائياً.
